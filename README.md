# Data Mining Lab - 2024

## Overview
This repository contains various data mining experiments utilizing different algorithms and datasets. Each lab focuses on a specific data mining technique and explores its application on various datasets.

## Labs

| Lab Name | Dataset |
| --- | --- |
| 1. Principal Component Analysis | [Students' Dropout Prediction Dataset](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success) |
| 2. Decision Tree | [Tic-Tac-Toe Endgame Dataset](https://archive.ics.uci.edu/dataset/101/tic+tac+toe+endgame) |
| 3. Naïve Bayes Classifier | [Bank Marketing Dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing) |
| 4. k-Nearest Neighbor | [Forest Covertype Dataset](https://archive.ics.uci.edu/dataset/31/covertype) |
| 5. Artificial Neural Network | [Fashion MNIST Dataset](https://www.kaggle.com/datasets/zalando-research/fashionmnist) |
